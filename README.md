# CodeAlpha E-Commerce Analysis

## Project Description

This project analyzes e-commerce sales data using Python, Pandas, and Matplotlib.

The project includes:
- Data cleaning
- Missing value analysis
- Duplicate value checking
- Statistical analysis
- Sales and profit analysis
- Category and regional analysis
- Monthly sales trend analysis
- Customer segment analysis
- Discount vs Profit analysis
- Top 10 products by sales
- Data visualization

## Tools Used

- Python
- Pandas
- Matplotlib

## Visualizations

1. Sales by Category
2. Profit by Category
3. Monthly Sales Trend
4. Sales by Customer Segment
5. Discount vs Profit
6. Top 10 Products by Sales

## Key Insights

- Technology has the highest sales and profit among the categories.
- Central region has the highest sales and profit.
- Consumer segment has the highest sales.
- November 2014 recorded the highest monthly sales.
- Higher discounts are generally associated with lower or negative profit.
- Smartphones appear frequently among the top-selling products.
